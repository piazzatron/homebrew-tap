# piazzatron/homebrew-tap

Homebrew formulas for [rostr](https://getrostr.sh), which gives every coding-agent session a name from a roster.

```sh
brew install piazzatron/tap/rostr
```

The formula in `Formula/` is generated and pushed by [rostr's releases](https://github.com/piazzatron/rostr/releases);
don't edit it by hand.
